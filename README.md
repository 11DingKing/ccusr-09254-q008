# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 补录工作队列

学期末补录请求通过 `/api/queue` 下的持久化工作队列处理：

- 评分规则可版本化（`POST /api/queue/rules` 创建新版本，`POST /api/queue/rules/{rule_id}/versions/{version}/activate` 切换启用版本），分数由毕业优先级、材料齐全度与老化因子（按等待时长加分，可设上限）组成，保证普通请求不会无限等待。
- 认领（`POST /api/queue/claim`）基于租约与条件更新，并发下同一请求只会被一名工作人员认领；续租、退回、完成均需持有效租约令牌，租约过期后条目自动可被回收。
- 退回补证（`POST /api/queue/items/{request_id}/return`）保留原等待起点 `wait_anchor`，等待时间不清零。
- 队列顺序完全由持久化字段与当前时刻计算，服务重启后重建顺序一致；`GET /api/queue/items` 预览当前认领顺序，`GET /api/queue/stats` 输出队列统计。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试


## 编译检查

```bash
python3 -m compileall -q app tests
```

测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询，以及补录队列的并发认领、时钟推进、规则切换、租约回收与重启顺序重建；运行过程中不需要单独的数据库或网络服务。
